# ChatSOL Client

A JavaScript-based client application for ChatSOL.

## Overview

This is the frontend client for ChatSOL, built with JavaScript, CSS, and HTML.

## Technology Stack

- **JavaScript**: 96.1%
- **CSS**: 2.8%
- **HTML**: 1.1%

## Getting Started

### Prerequisites

- Node.js (recommended)
- A modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Prajwal09-Walde/client-ChatSOL.git
cd client-ChatSOL
```

2. Install dependencies:
```bash
npm install
```

### Running the Application

```bash
npm start
```

The application will be available at `http://localhost:3000` (or your configured port).
